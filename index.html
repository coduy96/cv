How I build with AI

01 · CONTEXT

Spec before code

Each repo has an AGENTS.md or CLAUDE.md, a short product spec and architecture notes. The agent reads those first, so it follows my rules.

02 · DECOMPOSE

Small steps

I split big features into small tasks, each with a clear "done". We agree on a plan before any code gets written.

03 · VERIFY

Checks on every change

Type checks, unit tests and Playwright run after each change. When something fails, the error goes back to the agent to fix.

04 · REVIEW

I read every diff

Nothing merges until I've read it, especially auth, payments and database rules. Some parts I still write by hand.
